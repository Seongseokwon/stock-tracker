# StockPulse — 수익화 가이드

**최종 갱신:** 2026-05-19  
**전제:** 본 문서는 사업·법률 자문이 아닙니다. 한국·미국 **금융광고·투자자문·개인정보** 규정은 직접 확인하세요.

**관련:** [LEGAL-DISCLAIMER.md](./LEGAL-DISCLAIMER.md) (고지·면책 템플릿)

---

## 1. 이 프로젝트로 수익화가 가능한 이유

| 자산 | 활용 |
|------|------|
| 배포된 PWA | 트래픽·재방문·홈 화면 설치 |
| US+KR 관심목록 | 국내·해외 투자자 니즈 |
| URL 공유 | 바이럴·커뮤니티 확산 |
| 백엔드 프록시 | 유료 tier·API 키 분리 확장 가능 |
| Vanilla 스택 | 템플릿 판매·B2B 커스터마이즈 용이 |

**약점 (수익화 전 인지):** DB·로그인 없음, Finnhub 무료 한도, Yahoo 비공식, **투자 자문·매매 기능 없음** → “정보 제공 도구” 포지셔닝이 안전.

## 2. 가장 빠른 시도 순 (요약표)

| 순위 | 방식 | 첫 수익까지 | 개발량 | 월 예상(초기) | 리스크 |
|------|------|-------------|--------|--------------|--------|
| **1** | 후원·팁 (토스·카카오·Ko-fi) | **당일~3일** | 거의 없음 (푸터 링크) | ₩0~수만 | 낮음 |
| **2** | 면책·이용약관·개인정보 고지 | **1일** | 문서+푸터 1줄 | 필수(수익 전) | 미고지 시 법적 |
| **3** | 증권사·해외브로커 **제휴 링크** | **1~2주** (승인 후) | 푸터·모달 CTA | 제휴당 수천~수만 | **광고 표시 의무** |
| **4** | 소스·템플릿 판매 (Gumroad 등) | **3~7일** | README·데모 정리 | 건당 ₩1만~ | 라이선스 명시 |
| **5** | Google AdSense | **2~4주** | 광고 슬롯 HTML | 클릭당 소액 | 트래픽·정책 심사 |
| **6** | 프리미엄 기능 (종목 수·알림) | **2~4주** | 로그인·결제·DB | 구독 ₩990~ | 개발·환불·CS |
| **7** | 유료 데이터 재판매 | **수개월+** | API 계약 | 높음 | **Finnhub/Yahoo ToS 위반 위험** |

**이번 주 추천 조합:** **2 → 1 → 3** (고지 먼저, 후원 링크, 제휴 신청 병행)

## 3. Tier 1 — 당일~3일 (코드 최소)

### M-1. 후원·팁 링크

**할 일**

1. [LEGAL-DISCLAIMER.md](./LEGAL-DISCLAIMER.md) 푸터 문구 반영  
2. `frontend/index.html` 푸터에 링크 1~2개  
   - 예: 토스 송금 링크, Ko-fi, Buy Me a Coffee  
3. OG·카카오 공유 시 “개인 프로젝트·후원 환영” 한 줄 (선택)

**구현 위치:** `index.html` 하단, `style.css` `.site-footer`

**수익:** 불규칙·소액. 트래픽 100 DAU 이상부터 의미 있음.

---

### M-2. 법적 고지·면책 (수익화 전 필수)

투자 정보 앱은 **투자 권유·자문 아님**, **손실 책임 없음**, **데이터 지연**을 명시해야 제휴·광고·후원 시 신뢰도가 올라갑니다.

**할 일:** [LEGAL-DISCLAIMER.md](./LEGAL-DISCLAIMER.md) → `이용약관`·`개인정보처리방침` 페이지 또는 모달 (정적 HTML 1~2페이지)

**개발:** `frontend/legal.html`, `privacy.html` 또는 모달 + 푸터 링크

---

### M-3. 트래픽·전환 측정 (무료)

| 도구 | 용도 |
|------|------|
| Vercel Analytics | 페이지뷰 (설정 간단) |
| Google Analytics 4 | 유입·이벤트 |
| 카카오 공유·URL `?ref=` | 채널별 공유 추적 |

**이벤트 예:** `share_watchlist`, `install_pwa`, `affiliate_click`

수익화 실험 전 **기준선 DAU**를 잡지 않으면 개선 여부를 알 수 없습니다.

## 4. Tier 2 — 1~2주 (낮은 개발)

### M-4. 증권사·브로커 제휴(리퍼럴)

**적합한 위치**

- 푸터: 「국내 계좌 개설」 「해외 주식 (미국)」  
- KR 종목 모달 하단: 「이 종목 거래하기」→ 제휴 URL (새 탭)  
- US 종목 모달: 해외 브로커 링크  

**주의 (한국)**

- 금융상품 **광고**에 해당할 수 있음 → **광고 표시**, **위험 고지**  
- 제휴 프로그램 **별도 신청·심사** (즉시 링크 불가인 경우 많음)  
- 수익: 계좌 개설·첫 거래 시 CPA (수천 원~수만 원대, 프로그램마다 상이)

**할 일 체크리스트**

- [ ] 국내 증권사 제휴·파트너 프로그램 조사 (키움·한국투자·토스증권 등 공개 페이지)  
- [ ] 해외: Interactive Brokers, Webull 등 affiliate 여부  
- [ ] 링크에 `rel="sponsored noopener"` + 「제휴 링크」 문구  
- [ ] 클릭 로그 (GA4 이벤트 `affiliate_click`)

---

### M-5. 디스플레이 광고 (AdSense)

**조건:** 일정 트래픽, 콘텐츠 정책, **금융 콘텐츠** 심사  

**구현**

- 카드 목록 **하단** 1슬롯 (UX 훼손 최소)  
- 모달 내부는 광고 지양 (이탈·정책)  

**수익:** 초기 월 수백~수천 원 수준 가능. 트래픽 1만 PV/월 전후부터 검토.

---

### M-6. 소스·템플릿 판매

**팩 내용**

- 현재 repo (키 제외) + HANDOFF + 배포 가이드  
- 「Finnhub 프록시 + KR Yahoo + PWA」 보일러플레이트  

**판매 채널:** Gumroad, 크몽, GitHub Sponsors (후원형)  

**가격 가이드:** ₩9,900~49,000 (문서·QA 포함 여부에 따라)  

**라이선스:** 개인 1도메인 / 상업 별도 — `LICENSE` 파일 추가 권장

## 5. Tier 3 — 2~4주+ (제품화)

### M-7. 프리미엄 (Freemium)

| 무료 (현재) | 유료 아이디어 |
|-------------|----------------|
| 관심종목 20 | 50~100 |
| 알림 N개 | 무제한 + 이메일/푸시 |
| US 폴링 20s | 5s (서버 비용↑) |
| JSON 백업 | 클라우드 동기화 |

**필요 인프라:** 사용자 DB (Supabase/Firebase), 결제 (Stripe·토스페이먼츠), **서버 비용·Finnhub 유료 플랜** 산정

**빠른 검증:** 결제 전 **「프리미엄 대기자」 Google Form** 으로 의향 조사 (0코드)

---

### M-8. B2B·화이트라벨

- 동호회·스터디·유튜버용 **브랜딩 PWA** (로고·도메인만 변경)  
- 월 구독 ₩5만~30만 (유지보수 포함)  

**전제:** 커스텀 도메인, 안정 배포, SLA 문서

---

### M-9. 콘텐츠·커뮤니티

- 「오늘의 관심종목」 주 1회 뉴스레터 (Beehiiv·스티비)  
- 스폰서 1슬롯 (트래픽 확보 후)  

**StockPulse 연동:** URL 공유 기능으로 「이번 주 watchlist」 바이럴

## 6. 하지 말아야 할 것 (ToS·법무)

| 항목 | 이유 |
|------|------|
| Finnhub/Yahoo 데이터 **재판매 API** | 라이선스·ToS 위반 가능 |
| 수익률·매수 추천 문구 | 투자자문·불공정 광고 리스크 |
| API 키를 유료 사용자에게 **직접 노출** | 키 유출·요금 폭탄 |
| `.env`·Vercel 키가 포함된 zip 판매 | 보안 사고 |

## 7. 비용 vs 수익 (손익 감)

| 항목 | 월 비용(대략) |
|------|----------------|
| Vercel Hobby | $0 (한도 내) |
| Finnhub Free | $0 (429 한도) |
| Finnhub 유료 | $50+ (트래픽·프리미엄 시) |
| 도메인 | ₩1만/년 수준 |

**손익분기:** 제휴 계좌 **월 1~2건** 또는 AdSense **월 5만 PV** 또는 프리미엄 **유료 10명×₩990** 등 — 트래픽 없으면 Tier 1만으로는 거의 ₩0.
