## A. AI 종목 브리핑

관심종목 카드 클릭(모달)시 **현재 시각에 맞는 AI 요약 브리핑** 표시.

| 구간 | KR (KST) | US (ET) | 요약 내용 |
|------|----------|---------|-----------|
| `pre_open` | 09:00 전 | 정규장 전 | 전일 뉴스·주가 |
| `midday` | 12:00 이후 | 12:00 ET 이후 | 오전장 요약 |
| `post_close` | 15:30 이후 | 16:00 ET 이후 | 당일 종합 |

> 09:00~11:59(KR) 또는 장중 12:00 전은 「오전 브리핑은 12시 이후」 안내 표시.

**API:** `GET /api/briefing?symbol=AAPL&slot=auto`

**구현 단계 (A-*):**

| ID | 작업 | 상태 |
|----|------|------|
| A-0 | 슬롯 규칙 확정 | ✅ 2026-05-22 |
| A-1 | `/api/briefing` + 데이터 수집기 | ✅ 2026-05-22 |
| A-2 | 규칙 기반 MVP (LLM 없이) | ✅ 2026-05-22 |
| A-3 | LLM 연동 (서버 프록시) | ⬜ AdSense 수익 후 |
| A-4 | 모달 UI 「AI 브리핑」섹션 | ✅ 2026-05-22 |
| A-5 | 슬롯·거래일별 캐시 | ✅ 2026-05-22 |
| A-6 | `slot=null` UX 안내 | ✅ 2026-05-22 |
| A-7 | QA·면책 문구 | ✅ 2026-05-22 |

**환경 변수 (A-3 이후):** `OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY`

**제약:**
- KR 뉴스 없을 때 → 주가·차트 위주 요약 (K-3 후 보강)
- Vercel 30초 타임아웃 → 종목당 LLM 1회, Cron 선캐시 권장
- 프롬프트 원칙: 매수·매도 지시 금지, 제공 데이터만 인용

## B. 매크로 뉴스 피드

미국 거시·경제 뉴스를 한 곳에서 정리.

**API:** `GET /api/macro-news?category=market|economy|fed&limit=20`

**소스 후보 (N-0 조사 필요):**

| 소스 | 유형 | 비고 |
|------|------|------|
| Finnhub `market-news` | REST (기존 키) | 이미 사용 중 |
| Fed/BLS/SEC RSS | RSS | 무료·안정 |
| Yahoo Finance RSS | RSS | 비공식·변경 가능 |

> Bloomberg HTML 스크랩은 **ToS 위반 위험 → 절대 금지**. 링크 아웃만.

**구현 단계 (N-*):**

| ID | 작업 | 상태 |
|----|------|------|
| N-0 | 소스·약관 조사 | ⬜ |
| N-1 | `/api/macro-news` 백엔드 | ⬜ |
| N-2 | 수집·캐시 (Cron) | ⬜ |
| N-3 | 프론트 「미국 경제」패널 | ⬜ |
| N-4 | 카테고리·관심종목 연관 필터 | ⬜ |
