# 법적 고지·면책 — 템플릿 (StockPulse)

**최종 갱신:** 2026-05-19  
**용도:** 사이트 푸터·정적 페이지(`legal.html` 등)에 붙여 넣을 **초안**입니다.  
**반드시** 본인 상황에 맞게 수정하고, 필요 시 변호사·세무사 자문을 받으세요.

---

## 1. 투자 정보 면책 (필수 권장)

```
StockPulse(이하 「서비스」)는 이용자의 투자 판단을 돕기 위한 시세·차트·뉴스 등
정보를 제공하는 도구이며, 투자 권유·투자 자문·매매 대리를 하지 않습니다.

제공 정보는 Finnhub, Yahoo Finance 등 제3자 데이터이며,
지연·오류·중단이 발생할 수 있습니다.

이용자의 투자 손익에 대한 책임은 전적으로 이용자에게 있으며,
운영자는 어떠한 투자 손실에 대해서도 법적 책임을 지지 않습니다.
```

---

## 2. 제휴·광고 고지 (제휴 링크 사용 시)

```
서비스에는 증권사·금융기관 등 제3자의 제휴(리퍼럴) 링크가 포함될 수 있으며,
이를 통해 계좌 개설·거래 등이 이루어질 경우 운영자에게 수수료가 지급될 수 있습니다.
제휴 관계는 이용자의 추가 비용을 발생시키지 않을 수 있으나,
상품 조건은 각 금융사 약관을 따릅니다.
```

---

## 3. 개인정보 처리 (최소 수집 버전)

**현재:** 서버 DB 없음 — 관심목록·포트폴리오는 **localStorage**만.  
**L-* MVP 이후:** 일회용 로그인 사용자는 **관심종목 심볼**을 DB에 저장.

```
수집 항목: (서버 로그) IP, 접속 시각, User-Agent
          (L-*) user_id, 관심종목 심볼·종목명, 세션, 로그인 코드 해시(평문 미저장)
          (분석) GA4 등 — 별도 안내
저장: localStorage(전 사용자) + DB watchlist_items(로그인 사용자, L-*)
제3자: Finnhub, Yahoo, Frankfurter 등 API 호출 시 종목 심볼 전송 가능
권리: localStorage 삭제 / 로그아웃·문의 시 서버 데이터 삭제 요청
문의: [운영자 이메일 입력]
```

분석(GA4)·후원·제휴를 켜면 **개인정보처리방침 전용 페이지**를 권장합니다.
