개인정보처리방침

최종 갱신: 2026년 5월 21일 · 시행일: 2026년 5월 21일

StockPulse는 이용자의 개인정보를 소중히 여깁니다. 수집하는 정보는 서비스 운영에 필요한 최소한으로 제한하며, 제3자에게 판매하지 않습니다.

1. 수집하는 정보

항목 수집 방법 목적
로그인 코드 (SHA-256 해시) 서버 DB (Railway PostgreSQL) 본인 확인 및 접근 제어
세션 쿠키 (sp_sess) 브라우저 쿠키 (HttpOnly, 7일) 로그인 상태 유지
관심종목 목록 서버 DB + 브라우저 localStorage 관심종목 저장·동기화
포트폴리오·알림 설정 브라우저 localStorage (서버 미전송) 개인화 기능 제공
방문 통계 (IP 익명화) Google Analytics 4 (GA4) 서비스 이용 현황 분석

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 직접 식별 가능한 개인 정보
  • 금융 계좌 정보, 신용카드 정보
  • 위치 정보

3. 쿠키 및 로컬 저장소

3.1 세션 쿠키 (sp_sess)

  • 로그인 상태 유지를 위해 사용합니다.
  • HttpOnly, SameSite=Strict 속성으로 XSS 공격으로부터 보호됩니다.
  • 만료: 발급 후 7일, 또는 로그아웃 시 즉시 삭제.

3.2 localStorage

관심종목(sp_watchlist), 포트폴리오(sp_portfolio), 알림(sp_alerts), 테마(sp_theme)가 브라우저 로컬 저장소에 저장됩니다. 이 데이터는 서버로 전송되지 않으며, 브라우저 캐시 삭제 시 함께 삭제됩니다.

3.3 Google Analytics 쿠키

GA4는 _ga, _ga_XXXXXXXXXX 등의 쿠키를 사용하여 방문 통계를 수집합니다. 수집 데이터는 익명화 처리되며 개인 식별에 사용되지 않습니다. 브라우저 설정에서 거부하거나 Google Analytics 옵트아웃 도구를 이용할 수 있습니다.

4. 제3자 서비스

StockPulse는 서비스 제공을 위해 아래 외부 서비스를 이용합니다. 종목 조회 시 해당 심볼 정보가 API 요청에 포함될 수 있습니다.

서비스 용도 개인정보처리방침

Yahoo Finance (비공식) 한국 주식 시세·차트 Yahoo Privacy Policy

5. 데이터 보관 기간

  • 세션 쿠키: 발급 후 7일, 로그아웃 시 즉시 삭제
  • 서버 DB (관심종목, 세션 기록): 계정 비활성 1년 후 또는 삭제 요청 시
  • localStorage: 사용자가 브라우저 데이터를 삭제할 때까지

6. 이용자의 권리

이용자는 다음 권리를 행사할 수 있습니다.

  • 데이터 확인: 서버에 저장된 관심종목 목록 확인 요청
  • 삭제 요청: 저장된 데이터 전체 삭제 요청 (이메일 문의)
  • 쿠키 거부: 브라우저 설정에서 쿠키를 비활성화할 수 있으나, 로그인 기능이 동작하지 않을 수 있습니다.
